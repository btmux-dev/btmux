<Steps>

1. Start btmux, or install it as a [background service](installation.mdx#background-service):

   ```sh
   btmux
   ```

2. Open `http://127.0.0.1:8004`.

3. Read the access token. btmux creates it on first start and prints the file's
   path:

   ```sh
   cat "${XDG_STATE_HOME:-$HOME/.local/state}/btmux/state.token"
   ```

   On Windows, in PowerShell:

   ```powershell
   Get-Content "$env:LOCALAPPDATA\btmux\state.token"
   ```

4. Sign in with the username `btmux` and the token as the password.

</Steps>

The token stays the same across restarts. To use btmux from your phone or
other machines, see [Phones, tablets, and Tailscale](../features/phones-and-tailscale.mdx).
[Access and remote access](../configuration/access.md) covers token files for
profiles, rotating the token, and reverse proxies.
